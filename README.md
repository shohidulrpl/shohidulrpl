### About Me
I build lightweight web applications, automated operational workflows, and cloud-connected business tools that replace repetitive manual tasks.

- **Web & Utility Applications:** Building fast, browser-based tools and organizational portals deployed on **GitHub Pages** (`HTML5`, `CSS3`, `JavaScript`, `TypeScript`).
- **Workflow & Cloud Automation:** Designing webhook-driven attendance, reporting, and messaging pipelines with **n8n**, **Firebase**, and **Google Sheets**.
- **Data & Process Engineering:** Automating spreadsheets, data transformation, and browser tasks using **Python** (`Pandas`, `Selenium`, `OpenPyXL`) and **Excel / Power Query**.
- **Mobile & Creative Tech:** Developing native Android utilities in **Kotlin** alongside microstock vector/3D design and commercial audio production.
